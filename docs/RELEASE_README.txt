MSC Multiplayer - play My Summer Car with your friends
=======================================================

INSTALL (both players, same version)
  1. You need MSCLoader (the My Summer Car mod loader):
     https://www.nexusmods.com/mysummercar/mods/147
  2. Close the game.
  3. Double-click Install.bat in this folder. Done.

PLAY
  Host:   start the game from Steam, press F2 in the main menu,
          click "Host game", then "Invite friends", then press Continue.
  Friend: accept the Steam invite. Your game loads the host's world
          by itself. Your own save is backed up and put back
          automatically when you leave.

KEYS
  F2  multiplayer menu      T  chat       Tab  player list
  G   wave                  Enter at the passenger door  ride along

UNINSTALL
  Double-click Uninstall.bat.

Help, full guide and bug reports:
